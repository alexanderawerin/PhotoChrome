# Iconoteka editing controls

25 genuine Regular / Stroke paths, copied without geometry changes from the official [`02.01.00` release](https://github.com/iconoteka/iconoteka/tree/02.01.00), `icons.json`. `sources.json` identifies every original SVG. All use the official 24-unit viewBox; the stroke-style outlines are filled paths, not adjustable SVG strokes.

Only the required geometry is shipped. There is no runtime CDN, MCP integration or additional package dependency. `Iconoteka.tsx` supplies SVG accessibility defaults and inherits `currentColor`. Text labels carry each control's meaning.

The unmodified MIT license and copyright notice are included at [`public/licenses/iconoteka.txt`](../../../public/licenses/iconoteka.txt) and served in production at `/licenses/iconoteka.txt`.
